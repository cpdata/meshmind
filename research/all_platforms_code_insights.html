AI Agent Memory — Codebase Insights

Generated: 2025-10-15T03:23:53.470605Z

Mem0

  • FastAPI server exposes /api/v1/memories/ with payload field now 'text' (not 'memory').
  • SDK methods: Memory.add/search/update/delete; consolidation planner drives ADD/UPDATE/DELETE.
  • Supports multiple vector stores (e.g., Qdrant/Chroma/Azure AI Search); optional Neo4j graph.
  • OpenMemory MCP integrates with tools; hosted cloud at api.mem0.ai.

Graphiti

  • MCP server exposes tools (add_memory, search_facts, search_nodes, get_episodes, delete_episode, clear_graph).
  • Bi-temporal KG; search recipes include BM25 + semantic + traversal; RRF/MMR/cross-encoder; node-distance rerank.
  • CRUD classes EntityNode/EpisodicNode + EntityEdge/EpisodicEdge with save/delete/get_by_uuid.

Zep

  • Zep Cloud builds on Graphiti’s temporal KG; SDKs in Python/TS/Go.
  • README emphasizes valid_at/invalid_at and continuous learning; zepcli manages service.

LangChain

  • Provides memory modules (ConversationBuffer/Summary, VectorStoreRetrieverMemory, ConversationKGMemory).
  • Library-level; no canonical REST; persistence via user-provided stores.

LangGraph

  • Long-term memory via namespaces; thread stores for short-term memory.
  • Separates checkpointing vs memory; long-term memory stored as JSON docs.

LlamaIndex

  • ChatSummaryMemoryBuffer & Memory class; chat_store persistence; KnowledgeGraphIndex for relations.
  • Retriever ecosystem with rerankers; backend-dependent BM25; no bi-temporal KG.

AutoGen

  • AgentChat Memory protocol; RAG + Memory docs for persistent stores.
  • Multi-agent memory patterns; app provides actual storage engines.

MemGPT

  • Tiered memory architecture (short-term vs long-term vector store) to extend context.
  • Policies to move facts between tiers; summarization for context control.

CrewAI

  • Memory=True enables short-term, long-term, and entity memory; defaults to local Chroma/SQLite.
  • Community requests for custom memory stores; vector backends like Qdrant supported; Couchbase tutorial exists.

Haystack

  • Agent memory frequently modeled as list + RAG; BM25 retriever and rerankers available.
